# Roadmap

## Phase 1 - Foundation

- Monorepo, Docker, PostgreSQL, Redis, MinIO.
- API health checks.
- User registration, email activation, login, and profile update.
- Persisted sessions and logout.
- First web interface.
- Desktop shell.
- Desktop launcher and Windows installer without Tauri.
- Public/private channel UI and visual voice join/leave state.

## Phase 2 - Social graph

- Friend requests.
- Friends list.
- Blocking.
- Direct conversations.

## Phase 3 - Communities

- Server creation.
- Categories, text channels, voice channels, and private channel permissions.
- Members and membership lifecycle.
- Roles and permission checks.

## Phase 4 - Realtime messaging

- WebSocket gateway.
- Persistent messages.
- Typing indicators.
- Delivery confirmation.
- Reactions, replies, pins, edits, and deletes.

## Phase 5 - Media, voice, and admin

- S3-compatible uploads.
- Moderation tools and audit logs.
- Notifications.
- WebRTC signaling for voice, video, camera, and screen sharing.
- Bot applications and public API.
- Platform administration dashboard.
